# ref-antihallucination

> 学术文献检索的防幻觉核验机制：把"先找到原件、再核对身份、再核对摘要、最后核对论断"固化为可执行流程。
> 附带 **GB/T 7714-2025** 著录规则实施细节（2026-07-01 已实施）。

适用于任何需要让大模型检索文献、写综述、做引文核查的场景。核心不是"让模型更谨慎"，而是**让每一行输出都能被使用者在几十秒内独立推翻**。

---

## 它解决的四种"文献幻觉"

学术场景里模型造出来的东西，通常不是整篇编造，而是这四类：

| 类型 | 表现 | 本技能的拦截点 |
|---|---|---|
| **拼凑** | 真作者 + 真题名 + 假卷期；真题名 + 假 DOI | L1 逐字段比对（DOI 落地页 vs 注册机构元数据） |
| **张冠李戴** | DOI 真实，但指向完全另一篇 | L1 判据：DOI 真实 ≠ 引用正确 |
| **摘要脑补** | 没读摘要，按题名写出"研究内容" | L2 要求给出可在落地页 Ctrl+F 命中的技术细节 |
| **论断错配** | 引文全真，结论全错——文献并不支持你说的那句话 | L3 要求定位到章节/页码/图号，并标适用条件 |

第四类最隐蔽，危害也最大：**引文可查、格式规范，但结论是借来的**。

## 五级核验链

| 层级 | 核验对象 | 通过门槛 | 不通过时 |
|---|---|---|---|
| **P0 来源准入** | 出版商、期刊历史归属、ISSN | 不在用户配置的排除范围 | 强制排除或来源待查隔离；**不得据此认定论文虚构** |
| **L0 候选** | 双路检索、去重、版本关联 | 取得可追溯的候选原始线索 | 标"候选"，不得自称已读 |
| **L1 身份** | DOI 落地页 + 注册机构元数据 | 题名、作者、载体、年与标识符同属一篇 | 实质冲突剔除；网络失败进隔离区 |
| **L2 摘要** | 出版社或可信公开版摘要 | 真读到，并能准确概括对象、方法、发现 | 未取到不得写"摘要已核验" |
| **L3 论断** | 正文、图表、补充材料 | 论断有明确原文定位与适用边界 | 降为摘要支持、部分支持或未知 |

状态码：**P**（准入）/ **M**（身份）/ **A**（摘要）/ **C**（论断）/ **E**（出版状态），逐条标注后交付。

**四件事必须分开**：来源被排除 ≠ 论文虚构 ≠ 已被撤稿 ≠ 结论一定错误。

## 快速使用

### 1. 让模型去检索（复制提示词）

```
references/prompts.md
├─ P1  写综述、申报书、报告，一次 10–20 篇
├─ P2  日常追问补 3–5 篇，一段约束贴末尾
└─ P3  核查已有文献表、他人稿、旧稿
```

**丢给模型即可，不需要额外解释。** P1 含任务参数、来源准入配置、能力自检、L0–L3 流程、状态码、四块输出、交付前反查和停止规则。

### 2. 批量核验已有文献列表

```bash
python scripts/ref_verify.py 文献列表.txt --body 正文.md --report 核验报告.md
```

文献列表每行一条。输出六种状态：VERIFIED / CONFLICT / NOT_FOUND / CNKI_CHANNEL / POLICY / ERROR。

### 3. 交付前自查

按 `SKILL.md` 的检查清单逐项打勾。无法核验的候选删除而非猜填；数量不足就少给。

## 为什么内嵌 GB/T 7714-2025 代码表

主流模型的训练数据里没有 2025 版。只写"按 GB/T 7714-2025 著录"，模型会按 2015 版输出——**条目看着规范，标识已经过时**。所以 `references/gbt7714-2025.md` 把类型代码表、载体代码和新类型骨架直接给出来。

与 2015 版相关的关键变化：

| 项 | 2015 | 2025 |
|---|---|---|
| 文献类型 | 无预印本、无数据集 | **PP 预印本**、**DS 数据集** |
| EB 含义 | 电子公告 | **网站、网页** |
| 载体 | 无缩微资料 | **MM 缩微资料** |
| 核心术语 | 数字对象唯一标识符 | **永久标识符**（DOI / Handle / CSTR 等） |
| 电子资源 | 单列一类 | 拆分并入各类型，写 `[X/OL]` |

**PP 的附带价值**：它让"预印本冒充正式发表"从经验判断变成格式层面可查的事实——条目带 `[PP/OL]` 或平台为 arXiv / bioRxiv / ChinaXiv，就必须标注版本状态。

**永久标识符的附带价值**：中文预印本与数据集（如 ChinaXiv、国家基础学科公共科学数据中心）常只有 CSTR 没有 DOI。只认 DOI 会把真文献判成"无标识符"，这是旧口径的实质漏洞。

## 来源准入：可配置，不写死

排除某些出版商是**使用者的价值判断**，不该由提示词替使用者做。配置放在 P1 的【0 任务参数】里，三档：

```
A 出版商级排除：〔填出版商名〕含子刊、专刊、更名与继承期刊
B 平台级：不整体排除（SciELO、DOAJ、J-STAGE、Redalyc 等是期刊网络与出版基础设施）
C 单刊级排除：〔填刊名〕
```

两条实操要点：

- **识别看出版主体、ISSN、期刊继承链，不看刊名是否眼熟**。Hindawi 并入 Wiley 后，沿用原刊名的期刊仍属原血统；但不得因此扩大到 Wiley 其他无关期刊。
- **平台不等于出版商**。SciELO 是开放获取期刊集合，承载不同机构独立运营的刊物，把它和 MDPI 并列排除属类别错误。要排除只能落到具体期刊。

删掉配置即解除限制，模型无权自行增删。

## 已知边界

- 脚本的 Crossref `update-to` 字段并非覆盖所有撤稿，报 VERIFIED 不等于未撤稿；高风险文献须另查 Retraction Watch。
- 中文文献、政策文件、图书、学位论文、标准须走人工通道（见 `references/verify-channels.md`）。
- **提示词防的是"模型编造"，防不了"论文本身有问题"**。核心引文仍要自己看正文。
- 期刊另有格式要求时（Elsevier、IEEE、Nature 系列等），以投稿指南为准。
