# 文献核验通道手册

按文献类型选择核验通道。核心原则：**每条文献必须至少通过一条独立通道核验，否则不得写入文档**；发现方便 ≠ 证据权威（Tier 3 来源只能发现候选）。

## 一、分类型核验通道

| 文献类型 | 首选通道（Tier 1） | 备用通道（Tier 2） | 关键核对点 |
|---|---|---|---|
| 英文期刊（有 DOI） | Crossref API（`scripts/ref_verify.py` 自动执行） | doi.org 手工解析、出版商官网 | 题目、作者、期刊、年份、DOI 五要素 + 撤稿状态 |
| 英文期刊（无 DOI） | Crossref 书目检索（脚本自动，找到即回填 DOI） | 谷歌学术、出版商官网 | 同上；无 DOI 例外见第六节 |
| 中文期刊 | CNKI、万方、维普 | 谷歌学术 | 题名、作者（含顺序）、刊名、年卷期页七项逐一比对 |
| 政策文件 | 发文机关官网（gov.cn / moe.gov.cn / 中组部等） | 中国政府网政策文件库 | 发文全称 + 文号，逐字核对，六角括号〔〕 |
| 图书 | 出版社官网、国家图书馆目录 | WorldCat | 书名、作者、版次、出版社、年份、ISBN |
| **标准规范** | 全国标准信息公共服务平台（std.samr.gov.cn）、ISO/ASTM/ACI/RILEM 官网 | 标准化机构公告 | 标准号、名称、版次/年份、**现行/废止/被替代状态** |
| 学位论文 | CNKI 博硕士库、万方学位论文 | 学校机构知识库 | 作者、题目、学位授予单位、年份 |
| 会议论文 | 官方会议论文集平台（IEEE Xplore、ACM DL、Springer Link） | EI/Scopus | 题目、作者、会议名、年份、出版方、DOI；未评审摘要不得包装为期刊文章 |
| 预印本 | arXiv / SSRN / bioRxiv / medRxiv / ChemRxiv 官网 | — | 编号或 DOI、版本与日期；显式标注"预印本"，有正式版优先正式版 |
| 报告/白皮书 | 发布机构官网、机构知识库 | — | 标题、机构、年份、报告号、持久标识符 |
| 数据集 | 数据仓库（Zenodo、figshare、国家数据中心） | — | DOI/持久标识符、版本、发布日期 |
| 软件 | GitHub/Zenodo 发布页 | 论文（如软件有方法学论文） | 版本号、DOI；软件主页不能替代论文作为科学结果证据 |
| 报纸文章 | 原报官网（人民日报图文数据库、光明网） | — | 标题、发表日期、版面 |
| 网页/机构声明 | 直接访问原始 URL | web.archive.org 存档 | URL 可达、发布机构、发布日期 |

## 二、土木工程场景的标准文献核对（重点）

工程类论文/报告引用标准频繁，且标准更新换代快，必须核验**现行状态**：

1. 中国标准：全国标准信息公共服务平台查 GB（国标）、JTG（公路工程）、JGJ（建工行业）、TB（铁路行业）等，确认"现行/废止/被替代"；
2. 常见陷阱：GB 50011 等抗规类标准有多个年份版本（2001/2010/2016 局部修订），引用时年份必须与所依据版本一致；已被新版替代的旧标准只能在历史对比语境中引用；
3. 国外标准：ASTM/ACI/EN 官网核对标准号与版次（如 ACI 318-19 与 ACI 318-14 是不同版次）；不得用经销商或盗版 PDF 页面作为核验依据。

## 三、撤稿与出版诚信检查（Gate D 人工通道）

**自动检测覆盖边界（务必知晓）**：`ref_verify.py` 依赖 Crossref 的 update-to 字段，但出版商并非都登记撤稿链接（实测 Wakefield 1998 Lancet 撤稿案就未挂链）——**脚本报 VERIFIED 不等于未撤稿**。

高风险场景（正式投稿、综述、评审意见）按以下顺序补查：

1. **Retraction Watch Database**（retractiondatabase.org）：全球撤稿记录最全的公开数据库，按 DOI 或题目检索；
2. **PubMed**（生物医学类）：记录页直接显示 "Retracted Publication" 标注；
3. **出版商官网**：文章页横幅通常显示 RETRACTED / CORRECTION 提示；
4. WebSearch 检索"文章题目 + retracted/withdrawn/expression of concern"。

处理规则：已撤稿 → 默认排除（专门研究撤稿事件时须显式披露撤稿状态）；已更正 → 优先引用更正后记录并注明；关注声明（expression of concern）→ 谨慎引用并披露。

## 四、主张支持等级（F/A/M）判定细则

| 等级 | 含义 | 允许支撑的主张类型 |
|---|---|---|
| **F 全文核验** | 已查证相关结果、方法、讨论、表格或图 | 具体数值结果、机理与因果结论、实验条件、对比性结论 |
| **A 摘要核验** | 摘要明确陈述该观点 | 摘要中明确表述的宽泛结论 |
| **M 仅元数据** | 只确认文献存在及书目信息 | "该文献存在/涉及该主题"；不得作为具体科学结论的证据 |

执行要点：只有摘要可及时，引用不得比摘要更具体；不得从摘要外推未报告的数值、亚组结果或实验细节；引用综述中的数据时，若可及应回溯一手文献核验（一手文献核验不了就降级表述）。

## 五、中文文献的特殊说明

1. **Crossref 查不到 ≠ 不存在**：中文期刊 DOI 多由中国 DOI（ISTIC）注册，Crossref API 不可见。脚本自动把中文文献标记为 `CNKI_CHANNEL`，走 CNKI/万方人工核验；
2. **核对基准**：以 CNKI 条目页为准，逐项比对"题名—作者（含顺序）—刊名—年—卷—期—页码"；
3. **警惕同名**：中文重名作者多，核对作者单位与引文语境是否一致；
4. GB/T 7714-2015 格式转换只在核验**之后**进行，格式化不得改变书目事实。

## 六、无 DOI 期刊文献例外规则

默认排除无 DOI 的期刊文献。确属不可或缺（如历史性重要文献）时，同时满足以下条件才可保留：

1. 出版商/期刊官方档案确认该文献存在；
2. 第二个权威书目来源（WoS/Scopus/PubMed/权威目录）确认其元数据；
3. 在文献列表中显式标注 `[无DOI-双源核验]`。

此例外不得静默削弱严格模式；给无 DOI 的图书编造 DOI 同样禁止。

## 七、政策文件核对规范

1. 引用格式须含**正式发文全称**（书名号内一字不差）与**文号**（如"中办发〔2022〕XX 号"）；
2. 文号在官网原文页核对，正式文件用六角括号〔〕而非[];
3. 联合发文须列出全部发文机关，顺序与原文一致；
4. 领导人讲话引用须核对新华社通稿或《人民日报》原文，不得凭记忆转写"原话"；
5. 有修订版或后续文件的，显式区分引用的是哪一版。

## 八、捏造文献的常见特征（快速筛查）

- DOI 前缀（10.xxxx）不属于任何已知注册机构，或 DOI 解析后指向完全无关的文献；
- 期刊名过于宽泛或可疑（如 "Journal of Everything"）；
- 作者姓名中西混排、或姓氏与研究领域明显不匹配；
- 年份与卷期号对不上（该刊当年应在另一卷）；
- 页码格式异常（起始页大于结束页）；
- 声称"网络首发"却给出完整卷期页码；
- 多条引用的 DOI 高度雷同（仅尾缀不同）——典型批量捏造痕迹；
- 搜索引擎完全无痕：题目加引号精确检索零结果。

## 九、"宁缺毋滥"执行口径

| 情形 | 处理 |
|---|---|
| 五要素全部核对通过 | ✅ 放行写入 |
| 任一要素核对不上 | ⚠️ 先尝试修正（可能是笔误）；无法修正即删除 |
| 检索不到任何候选 | ❌ 删除该条，以可核验文献替代 |
| 检索条件所限无法完成核验 | ❌ 不得保留存疑条目；宁可减少文献数量 |
| 正文引用了但列表缺失 | ❌ 补齐或删除正文引用，二者必居其一 |
| 列表有但正文未引用 | ⚠️ 补引用或删条目，保持一一对应 |
| 用户要 20 条只验出 13 条 | ✅ 交付 13 条并明说缺口，绝不凑数 |
